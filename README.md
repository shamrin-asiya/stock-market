# 📈 Real-Time Stock Monitor

A real-time stock market monitoring web application that provides live stock updates, price tracking, interactive visualizations, and market trend analysis. This project helps users monitor stock performance efficiently through an easy-to-use interface.

---

## 🚀 Features

- 📊 Live stock price monitoring  
- 🔍 Search stocks using ticker symbols  
- 📈 Interactive charts and data visualization  
- ⏱ Real-time market updates  
- 💹 Historical stock data analysis  
- 🖥 Clean and user-friendly interface  
- 🌐 Responsive web application  

---

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Plotly
- yFinance API
